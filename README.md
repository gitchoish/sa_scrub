# 🛡️ 네이버 검색광고 침해 모니터링 시스템 (SA Scrub)

네이버 브랜드 검색어(키워드)에 노출되는 무단 경쟁사 광고(파워링크 및 쇼핑검색 광고)를 실시간 모니터링·스크린샷 캡처·신고 서식 생성 및 자동 이메일 발송하는 대시보드 시스템입니다.

---

## 📌 수집 대상 지면 (모바일 & PC 동시 지원)
- **📱 모바일(Mobile) 네이버 검색 결과** (`m.search.naver.com`)
  - **파워링크**: 상단 파워링크 섹션 침해 광고주 수집 (자사몰 도메인/스토어명/제외 경쟁사 자동 필터)
  - **쇼핑검색 광고**: 모바일 쇼핑 섹션 내 뱃지 및 과금 트래킹 도메인(`adcr.naver.com` 등) 기반 정밀 광고주 수집
- **💻 PC(Desktop) 네이버 검색 결과** (`search.naver.com`)
  - **파워링크**: PC 파워링크 지면 내 침해 광고주 수집 및 스크린샷 증빙
  - **쇼핑검색 광고**: 최신 PC 네이버플러스 스토어 및 쇼핑 섹션 광고주 수집 및 스크린샷 증빙

---

## 💻 다른 PC에서 실행하는 방법 (담당자 인수인계 가이드)

> 💡 **Node.js 설치 불필요!** 웹 화면(대시보드)이 내장 빌드되어 있어, 상대방 PC에는 **Python 단 1개만 설치**하면 즉시 구동됩니다.

### 1단계: Python 설치 (최초 1회)
1. **Python (3.10 이상 권장)** 다운로드: [공식 다운로드 링크](https://www.python.org/downloads/)
2. ⚠️ **[가장 중요]** 설치 화면 맨 첫 페이지 하단의 **`Add Python to PATH` (또는 `Add python.exe to PATH`) 체크박스를 반드시 체크**하고 [Install Now]를 클릭합니다.

---

### 2단계: 프로젝트 전달 및 다운로드
- **방법 A (추천 - 사내 전달 시)**: 
  - 현재 프로젝트 폴더 전체를 ZIP으로 압축하여 메신저(슬랙/잔디/카톡)나 사내 드라이브로 전달 (현재 설정된 키워드/이메일 세팅 유지)
- **방법 B (GitHub 이용 시)**:
  - GitHub 페이지(`https://github.com/gitchoish/sa_scrub`)에서 `Download ZIP` 또는 `git clone`

---

### 3단계: 원클릭 초기 셋업 (최초 1회)
- 폴더 안의 **`setup.bat`** 파일을 더블 클릭하여 실행합니다.
- 파이썬 필수 패키지와 크롬 캡처 엔진(Playwright)이 자동으로 설치됩니다. (약 1분 소요)

---

### 4단계: 프로그램 실행
- 폴더 안의 **`run.bat`** 파일을 더블 클릭합니다.
- 잠시 후 **기본 웹 브라우저가 자동으로 열리며 대시보드 화면(`http://localhost:8989`)**이 나타납니다!

---

## ⚙️ 주요 기능 및 설정
- **모니터링 대상 키워드**: 대시보드 좌측에서 스캔할 키워드 등록/삭제 (자동 실시간 저장)
- **개별 퀵 스캔(▶)**: 특정 키워드 1개만 메일 발송 없이 빠르게 화면에 캡처·테스트
- **내 브랜드 제외 필터**: 자사 도메인 및 스토어명 등록하여 자사 광고 수집 제외
- **수집 제외 경쟁사 필터**: 쿠팡, G마켓 등 굳이 신고할 필요 없는 대형사 상호명 등록 시 수집 제외
- **자동 정기 스케줄러 & 이메일 발송**: 주기(예: 30분, 180분) 설정 시 백그라운드 자동 수집 후 네이버 권리침해 신고용 엑셀 및 스크린샷 압축파일 첨부 이메일 발송
